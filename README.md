# Homebrew tap for Socketchat

[Socketchat](https://socketchat.org) is encrypted group chat with a server you run yourself.

```sh
brew install sachio222/tap/socketchat
```

Then see the [quick start](https://docs.socketchat.org) to set up a server or join one.

The formula installs the prebuilt programs from the [Socketchat releases](https://github.com/sachio222/socketchat_v4/releases) and checks each download against its published SHA-256.
